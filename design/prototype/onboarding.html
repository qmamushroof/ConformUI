First run

Check a page against its design

ConformUI turns your design into a contract of checkable requirements, measures your page against it, and writes the failures as a prompt for your coding agent.

Try the sample Start a project

The sample is a landing page with Desktop and Mobile captures and a 19-requirement contract, ready to run.

This browser can run Gemini Nano, but the model isn't downloaded yet.

With it, contract extraction stays on this device. Without it, ConformUI asks before using the cloud, or you write requirements yourself.

The loop

  1. 1.Contract

    Requirements read from your design. You review them, add your own, and lock the list.

  2. 2.Run

    Screenshots and a DOM snapshot of your page, checked against every requirement with measured numbers.

  3. 3.Fix prompt

    The failures as one paste-ready prompt: selector, design value, actual value and what to change.

  4. 4.Re-verify

    New captures after the fix show what is resolved, what remains and what regressed.

Three engines, always named

Every requirement, finding and trace row says which engine produced it.

On-device
Gemini Nano in Chrome. First pass stays on this device.
Cloud
Gemini through Firebase. Only when you allow it, per project, or for Deep Analysis.
Measured
Deterministic engine. Every number comes from here, never from a model.
