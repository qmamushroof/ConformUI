# 4.11 demo

**[◀ 4.10 export](04-10-EXPORT.md)** · [SPEC index](../SPEC.md) · **[4.12 settings ▶](04-12-SETTINGS.md)**

`src/features/demo` (kernel only) + `sample-site/` + `scripts/capture-sample.mjs`. One-click sample Project with genuine, reproducible captures. Realises PRD-F-10, PRD §10, PRD-D-22, PRD-M-01, PRD-M-02, PRD-M-13, PRD-M-14, PRD-R-01.

## 4.11.1 Public API

```ts
export interface SampleAssets { design: { desktop: Blob }; flawed: Record<'desktop' | 'mobile', { image: Blob; dom: DomSnapshot }>;
  fixed: Record<'desktop' | 'mobile', { image: Blob; dom: DomSnapshot }>; contract: Contract; precomputed: PrecomputedJudged /*kernel*/ }
export function loadSampleAssets(): Promise<SampleAssets>;                  // lazy: import.meta.glob(…, { query: '?url' }) + fetch
export function compareWithVerified(ai: Requirement[], verified: Requirement[]) /*kernel iou*/: { matched: string[]; missing: string[]; extra: string[] }; // PRD-M-14
export const TrySampleButton, SampleBanner, LoadFixedButton: React.FC<…>;
```

`app` builds the sample Project via `ProjectsService` + `ContractService.loadCommitted` (demo never imports other features).

## 4.11.2 Sample content (PRD-F-10.1..10.5; PRD-D-28: fictional, unnamed sample site; original copy and SVG artwork)

The sample has no brand name. Its nav logo spot shows a generic placeholder wordmark **"Sample Co."** (simple box + text mark), so "Navigation contains logo, four links and a primary button" stays checkable.

| Asset | Source | Output (committed, `src/features/demo/sample/`) |

Pages use only bundled assets (an OFL-licensed font with its licence file in `sample-site/assets/`, inline SVG art) so renders are stable across machines.

## 4.11.4 Rules

| ID | Rule |
|---|---|
| `SPEC-DEMO-02` | **Try the sample** (one click, PRD-F-10, PRD-M-13): creates Project "Sample landing page" with the desktop design, flawed captures + snapshots, and the verified Contract active; opens the Project with **Run** as primary action (2 clicks to Findings). Re-clicking creates a new copy. |
| `SPEC-DEMO-03` | **Extract contract** on the sample runs the real AI path (demo beat "Private contract") and shows the result in a comparison panel: "AI proposed N requirements; M match the verified contract" (`compareWithVerified`: same category and region IoU ≥ 0.5), with "Use AI contract" / "Keep verified contract" (S9). The AI result is stored as `pendingAiContractId` and becomes active only on **Use AI contract** (`SPEC-CON-09`). Matching uses kernel `iou` (`SPEC-KERNEL-10`). |
| `SPEC-DEMO-04` | **Load fixed implementation** (sample Projects only): replaces both captures and snapshots with the fixed set, then the user clicks Re-verify (PRD §10 beat "Re-verify"). |
| `SPEC-DEMO-05` | Pre-computed fallback (PRD-D-22): used only on sample Projects when the AI path is `needs-consent`, `blocked` or fails. Extract contract on a sample is an explicit user action: when the plan is `needs-consent` the consent sheet opens as on any Project. The pre-computed extraction is shown only on Decline, `blocked`, or failure, via `ContractService.loadPrecomputedExtraction` (§4.7.1). Run-time behaviour: `SPEC-RUN-13`. After a failed Deep request, on user click "Show pre-computed result", Deep refinements come from `precomputed/` via `DeepService.applyPrecomputed` (§4.9.1). Every such item and the Run carry `origin:'precomputed'` / `run.precomputed:true` and the banner "Sample results (pre-computed)". Measured/Visual results are always computed live. |
| `SPEC-DEMO-06` | Assets are lazy-loaded (not in the initial bundle) and precached by the service worker so the sample opens offline (PRD-F-12.1). Each PNG ≤ 1.5 MB; all sample files ≤ 8 MB total (`scripts/check-size.mjs`). |
| `SPEC-DEMO-07` | `scripts/capture-sample.mjs` (`npm run sample:capture`): Playwright Chromium; for each page/viewport: `setViewportSize`, full-page screenshot, then `page.evaluate` of `snippetSource` with `window.copy` stubbed to capture the JSON; writes outputs; prints a SHA-256 list. Running it is a manual step; outputs are committed (PRD-F-10.4). |
| `SPEC-DEMO-08` | [P1] Hosted sample pages: `sample-site/` copied to `dist/sample-site/` with a "Run the DOM snippet here" note (PRD-F-10.6). |

## 4.11.5 Acceptance tests

Node: verified Contract against flawed assets → PRD-M-01 table (1–6 Fail with listed severity/check type; 7 Needs review via precomputed Judged; no Critical/Major false positive); fixed vs flawed → 6 resolved, 1 remaining (`R-06`), 0 new/regressed (PRD-M-02). E2E: two clicks from onboarding to Findings, also with device `unavailable` (no modal; pre-computed Judged items labelled, "Allow cloud to judge live" visible); offline second visit opens the sample.
