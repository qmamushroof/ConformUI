# 5. UI

**[◀ 4.13 app + PWA](04-13-APP-PWA.md)** · [SPEC index](../SPEC.md) · **[6. Security, Privacy, Performance ▶](06-SECURITY-PRIVACY-PERFORMANCE.md)**

Tailwind CSS v4 (`@import "tailwindcss"` + `@theme` tokens, no `tailwind.config.js`). Desktop-first layout that reflows to 320 px (PRD §5 personas). Theme follows `prefers-color-scheme` (S10). Not a chatbot: no free-text chat input anywhere (PRD-P-08).

## 5.1 Screens (PRD §8 core flow)

| Screen | Contents |
|---|---|
| Projects `/` | list cards (name, viewport chips, last Run date, Pass/Fail/Review counts with icons, "Sample" tag), **New project**, **Try the sample**; empty state per PRD §8 |
| Project `/p/:id` | stepper "Design → Contract → Captures → Run → Fix → Re-verify" showing the next action; per-viewport columns (Desktop, Mobile): design drop zone, capture drop zone, DOM snapshot status + "Paste snapshot" / "Get the snippet"; Engine panel compact (badge, Download, enable steps); Run history |
| Contract `/p/:id/contract` | **Extract contract** (disabled without design, with format hint), progress per band, Requirement table grouped by viewport (`SPEC-CON-08`), design image with region outlines (hover/focus a row highlights its region), Accept all / per-row actions, Add requirement form, Export (MD/JSON), sample comparison panel (`SPEC-DEMO-03`) |
| Run `/p/:id/run/:runId` | summary bar (counts, re-verify line, viewport tabs), Findings list (left, sorted `SPEC-RUN-08`), Finding detail (right): `ComparisonView` + measurements + fix + condition + Engine; Passing / Not checked collapsible lists; Engine trace table; actions **Deep Analysis**, **Copy fix prompt**, **Export report**, **Re-verify** |
| Snippet `/snippet` | code block (read-only, monospace, scrollable), **Copy snippet**, 3 numbered steps, privacy line "Reads layout, text and styles only; sends nothing" |
| Settings, Onboarding | §4.12 |
| Sheets (modal) | `ConsentSheet` (project cloud consent), `DeepConfirmSheet`, confirm delete / clear data |

`SPEC-UI-01` **ComparisonView** (PRD-F-05.1, PRD-F-05.4): design crop and capture crop side by side (stacked < 900 px), same CSS scale, region outlined on both (design: solid `accent`; capture: dashed `text`); **Diff overlay** toggle button (`aria-pressed`) blends the pixelmatch mask (magenta, 60 % opacity) over the capture crop; **Full page** toggle shows whole images scaled to the pane width (no horizontal scroll), scrolled vertically so the region is centred, the two panes scrolling together by proportion; a presence failure captions the empty implementation crop "Nothing drawn here". Selecting a Finding (click or Enter) highlights its region on both images and updates `?f=`. The **Full page** toggle may be cut (ROADMAP cut list); side-by-side crops, region outlines and the Diff overlay are required.

## 5.2 Design tokens (`SPEC-UI-02`, PRD-D-31, S30; contrast = WCAG 2.1 relative luminance, computed 2026-11-25 from `design/tokens.json`: 64 pairs, 0 below AA)

Source of truth is `design/tokens.json`; `src/app/styles/tokens.css` (CSS variables: primitives + semantic roles, light by default, dark via `prefers-color-scheme`) and `src/app/styles/tokens.tailwind.css` (the `@theme` mapping, imported after `@import "tailwindcss"`) are generated from it and never hand-edited. The `[data-theme]` selectors in the generated `tokens.css` are inert in release 1 (S10); the prototype's Theme select is not built. No hex literals in components (grep test). Four hues only: accent blue (owner `#2563EB`), danger red, success green, and `diff` magenta for the overlay. Neutrals are `oklch(L 0.003–0.018 260)` primitives; ≈ hex given for reference.

No severity or review hues and no tinted `*-bg` backgrounds: severity, Needs review, Inferred and Not checked are ink (`text`/`text-muted`) distinguished by shape and word (§5.3).

Typography: IBM Plex Sans 400/500/600 for all UI; IBM Plex Mono 400/500 only for code, IDs, selectors and dimension labels; self-hosted (§2.2, `SPEC-PWA-03`); tabular numerals globally. Scale 12 / 14 / 16 / 18 (lead) / 20 / 28 px (24 px `2xl` is reserved, unused): body 16 px / 1.5; h1 28 px / 1.2 / 600; h2 20 px / 600; h3 16 px / 600; 12 px is the minimum. Spacing scale 4 px; radius 3 px (tags), 4 px (buttons, inputs), 6 px (cards, panes, sheets); min target 44×44 px.

`SPEC-UI-03`: `tests/unit/contrast.test.ts` parses `tokens.css` (resolving `oklch()` primitives) and asserts, in light and dark, every pair above: `text`, `text-muted`, `text-subtle` on `bg`/`surface`/`surface-raised`/`surface-sunken` and `text`, `text-muted`, `accent` on `accent-subtle` (≥ 4.5:1); `accent` on `bg`/`surface`; `accent-fg` on `accent`/`accent-hover`; `danger-fg` on `danger`, `success-fg` on `success`; `danger` on `bg`/`surface`/`surface-raised` (≥ 4.5:1, used as text); `success` on `bg`/`surface` (≥ 4.5:1); `border-strong` and `focus` on `bg`/`surface` (≥ 3:1).

## 5.3 Status, severity, label, engine: never colour alone (`SPEC-UI-04`, PRD-P-12)

| Item | Icon + text + shape |
|---|---|
| Severity | in ink, no hue: Critical: filled octagon "Critical"; Major: filled triangle "Major"; Minor: outline circle "Minor" |
| Status | Pass: check "Pass" (`success`); Fail: cross "Fail" (`danger`); Needs review: dashed-circle "?" icon "Needs review" (ink); Not checked: muted dash "Not checked: <reason>" (`text-muted`) |
| Label | Explicit: solid tag "Explicit"; Inferred: dashed tag "Inferred (advisory)" |
| Engine | `EngineBadge` (`SPEC-SET-09`): chip icon "On-device", cloud icon "Cloud", ruler icon "Measured" |
| Re-verify change | Resolved ↑ check (`success`), Remaining ● (`danger`), New +, Regressed ↓ (`danger`), Still passing = ; each with text |

## 5.4 State screens (`SPEC-UI-05`, PRD §8 empty/error states; one `StateNotice` component, copy keyed by `ErrorCode`/reason in `app/copy.ts`)

| State | Copy (short) |
|---|---|
| No projects | "Check a page against its design: build a contract, run it, hand the fixes to your coding agent." + Try the sample / New project |
| No design | Extract disabled: "Add a design image (PNG, JPEG or WebP, up to 20 MB). From a design tool, export the frame as PNG." |
| No capture for a viewport | rows show "Not checked: no capture for Mobile" |
| `IMAGE_UNSUPPORTED` / `IMAGE_TOO_LARGE` | "Use PNG, JPEG or WebP up to 20 MB and 8192 px per side." |
| `SNAPSHOT_INVALID` | first 5 problems + "The run will use images only." |
| Device unavailable / flag / downloading | Engine panel copy (`SPEC-SET-01`) + "Use cloud for this project" / manual requirements |
| Offline | "You're offline. Measured and Visual checks still run; AI checks and Deep Analysis wait for a connection." |
| `QUOTA_EXCEEDED` / `DAILY_CAP` | "Cloud limit reached. Your results are kept; try again later." |
| `AI_BAD_OUTPUT` | item: "Needs review: the model's answer could not be read." |
| `APPCHECK_FAILED` / `AI_FAILED` / `CLOUD_DISABLED` | "Couldn't reach the cloud model. Nothing was lost." / "Cloud analysis is paused." |
| `STORAGE_UNAVAILABLE` | "Couldn't open local storage. Nothing was deleted." + Reload |

Each code has copy and a component test. `StateNotice` is exported by `@projects` (`features/projects/ui`); it takes its copy as a `notice` prop (`stateCopy[code]` from `app/copy.ts`), because features never import `app`; `app` passes it to other features as a render prop (S13).

`SPEC-UI-07` Copy punctuation (S30): no em dash in any UI string (`copy.ts`, component text, `aria-label`, manifest, toasts); use a colon, full stop or comma instead. En dash only for numeric ranges ("202–238 px"); the minus sign (−) for negative numbers ("−88"). A unit test scans `copy.ts` for U+2014.

## 5.5 Accessibility (WCAG 2.1 AA, `SPEC-UI-06`, PRD-P-12, PRD-M-11)

| Rule | Detail |
|---|---|
| Semantics | one `h1` per route; `header/nav/main`; Findings list is a `listbox` (`aria-activedescendant`) or list of buttons; Run completion announced in an `aria-live="polite"` region ("Run complete: 6 fail, 1 needs review") |
| Keyboard | everything operable; Findings: Up/Down moves selection when the list has focus, Enter opens detail; ComparisonView toggles are buttons; no single-key global shortcuts; sheets trap focus, Esc cancels, focus returns to trigger |
| Images | crops have `alt` "Design: <requirement statement>" / "Implementation: …"; diff overlay described in text ("12% of the region differs") |
| Forms | labels bound; errors via `aria-describedby`; drop zones are buttons that open the file picker |
| Contrast / non-text | §5.2; never colour alone (§5.3) |
| Reflow / targets | usable at 320 px and 200 % zoom without horizontal page scroll (comparison images scroll inside their own region); targets ≥ 44×44 |
| Motion | `prefers-reduced-motion` disables transitions; progress via `role="progressbar"` |
| Verification | axe on Projects, Project, Contract, Run, Finding detail, Settings, Onboarding, Snippet in light and dark: zero serious/critical; manual keyboard pass of the core flow before submission |
